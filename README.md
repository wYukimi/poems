# Poems

1. Put poem `.txt` files in the `poems/` folder.
2. Add them to the `poems` array in `script.js`.
3. Open the project using a local server for testing (e.g. `python3 -m http.server`) — opening `index.html` directly via `file://` may block `fetch()` due to browser security.
4. Upload the project to GitHub.
5. Enable GitHub Pages.
